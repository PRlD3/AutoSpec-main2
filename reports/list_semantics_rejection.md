# 列表语义显式拒绝说明

## 目的

本轮将剩余的 GCC 编译失败前移到 Python-to-C 转换阶段。对于当前 C 表示无法保持 Python 语义的列表操作，转换器现在直接记录明确失败原因，不再生成不可编译的 C 文件。

## 拒绝规则

| Python 语义 | 失败记录 | 当前原因 |
|---|---|---|
| 列表真值判断，例如 `if not arr` | `不支持列表真值判断：需要定义空列表与非空列表语义` | `IntList` 不是可直接用于 C `!` 的标量；需要明确空列表判定规则 |
| 列表比较，例如 `list1 == sorted(list1)` 或切片与列表比较 | `不支持列表比较：需要实现按元素比较语义` | C 结构体不能直接使用 `==`；需要实现长度和逐元素比较 |
| 列表拼接，例如 `arr1 + arr2` | `不支持列表拼接：需要实现 IntList 连接语义` | 当前 `+` 仅表示整数运算；需要分配新列表并复制两侧元素 |

## 本轮样例

| 任务 | 原编译错误 | 当前转换阶段结果 |
|---|---|---|
| `Mbpp_463` | `!arr` 类型错误 | 显式拒绝列表真值判断 |
| `Mbpp_476` | `!nums` 类型错误 | 显式拒绝列表真值判断 |
| `Mbpp_567` | `IntList == IntList` 类型错误 | 显式拒绝列表比较 |
| `Mbpp_597` | `sorted_int_list(arr1 + arr2)` 类型错误 | 显式拒绝列表拼接 |
| `Mbpp_69` | 切片结果与列表比较类型错误 | 显式拒绝列表比较 |

## 回归结果

在实现版本选择策略更新后重新处理全部 399 条记录：

- C 生成成功：47
- 转换阶段失败：352
- GCC 编译成功：47
- GCC 编译失败：0

这表示所有生成的 C 文件均可通过 GCC 编译。原先的 5 个列表语义样例仍被准确归入转换阶段失败；其中 `Mbpp_69` 因选择验证成功但当前转换器不支持的 `join/map` 实现而提前失败，不再生成列表比较相关的 C 编译错误。

## 后续实现方向

- 为 `IntList` 增加 `is_empty_int_list`，将列表真值转换为 `length != 0`。
- 增加 `equal_int_list`，按长度和元素实现 Python 列表相等比较。
- 增加 `concat_int_lists`，分配容量并按顺序复制两个列表。
- 实现后保留当前拒绝测试，确保新语义不会重新产生编译阶段失败。
